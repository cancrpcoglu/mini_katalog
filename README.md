
# Mini Katalog Uygulaması

Basit bir Flutter ürün katalog uygulaması.

## Özellikler
- Ürün listeleme (GridView)
- Ürün detay sayfası
- Sepet sistemi
- Ürün arama ve filtreleme

## Kullanılan Teknolojiler
- Flutter 3.41.2
- Dart 3.11.0
- http paketi
- wantapi.com (Mock API)

## Çalıştırma
```bash
flutter pub get
flutter run
```
